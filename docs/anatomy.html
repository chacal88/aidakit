§1 · mental model §1 · modelo mental

Two halves that never blur

Duas metades que nunca se misturam

§3 · the flow §3 · o flow

A state machine declared in YAML

Uma máquina de estados declarada em YAML

A flow is a sequence of steps. Each step resolves an outcome and routes to the next one through on_result[outcome], on_success or on_failure — backwards included, which is how a failed gate hands the work back to the previous step. No implicit graph: the whole topology is in the file.

Um flow é uma sequência de steps. Cada step resolve um outcome e roteia para o próximo por on_result[outcome], on_success ou on_failure — inclusive para trás, que é como um gate reprovado devolve o trabalho ao passo anterior. Nada de grafo implícito: a topologia inteira está no arquivo.

§4 · the central point §4 · o ponto central

Inversion of control

Inversão de controle

The engine never dispatches a skill or a subagent. That is Claude's job. The engine reaches the step, pauses carrying the target, and waits. Each half solves what the other solves badly: the engine guarantees order, gate and state; the model does the work that demands judgement.

O engine nunca despacha uma skill ou um subagente. Isso é trabalho do Claude. O engine chega no step, pausa carregando o alvo, e espera. Cada metade resolve o que a outra resolve mal: o engine garante ordem, gate e estado; o modelo faz o trabalho que exige julgamento.

engine pauses pausa Reaches the invoke step and stops, saying what the target is and which outcomes it accepts. Chega no step invoke e para, dizendo qual é o alvo e quais outcomes ele aceita.
claude dispatches despacha Actually runs the skill or the subagent, in its own context, with that role's tools. Roda a skill ou o subagente de verdade, em contexto próprio, com as ferramentas daquele papel.
claude resume Calls resume <flow_id> <outcome> [key=value …] handing the result back. Chama resume <flow_id> <outcome> [chave=valor …] devolvendo o resultado.
engine routes roteia Validates the outcome against the declared ones, persists the context and decides the next step. Valida o outcome contra os declarados, persiste o contexto e decide o próximo step.

Where the step declares structured outputs, the resume is fail-closed: without the values, the engine re-pauses instead of proceeding with data missing. That is how the change-id resolved by one step arrives intact at every following step, instead of each one reinterpreting the original phrasing of the request.

Onde o step declara saídas estruturadas, o resume é fail-closed: sem os valores, o engine repausa em vez de seguir com dado faltando. É assim que o change-id resolvido por um passo chega intacto em todos os passos seguintes, em vez de cada um reinterpretar a frase original do pedido.

§5 · state §5 · estado

The flow outlives the session

O flow sobrevive à sessão

The engine is single-threaded by decision: it pauses and resumes against state on disk, which is exactly what survives a crash, a /clear or a week-long gap. Two folders per project: state/<flow_id>.json is the resumable state, logs/<flow_id>.log is the log in JSON lines.

O engine é single-thread por decisão: pausa e resume contra estado no disco, o que é exatamente o que sobrevive a um crash, a um /clear ou a uma semana de intervalo. Duas pastas por projeto: state/<flow_id>.json é o estado resumível, logs/<flow_id>.log é o log em JSON lines.

The CLI is a single binary: node governance/cli.js start|resume|status|summaries|abort|list. Every start, resume and status prints the progress table first — every step declared in the YAML, marked done / current / pending. That is the position layer. Under a finished step comes the second line, the narrative layer: the one-line summary that step emitted.

A CLI é um binário só: node governance/cli.js start|resume|status|summaries|abort|list. Todo start, resume e status imprime primeiro a tabela de progresso — todos os steps declarados no YAML, marcados done / current / pending. Isso é a camada de posição. Debaixo de um step concluído aparece a segunda linha, a camada de narrativa: o resumo de uma linha que aquele passo emitiu.

A step re-visited by a back-edge overwrites nothing: it gets a new entry with the visit number, so the history shows the plan was redone twice instead of hiding it.

Um step re-visitado por back-edge não sobrescreve nada: ganha uma entrada nova com o número da visita, então o histórico mostra que o plano foi refeito duas vezes em vez de esconder isso.

Where the process stops being trust

Onde o processo deixa de ser confiança

Every validator in the kit has the same contract — exit 0 passed, exit 1 failed, exit 2 infra error; JSON on stdout, human report on stderr. A flow calls a validator as a runs step, so a failure is routing, not a suggestion.

Todo validador do kit tem o mesmo contrato — exit 0 passou, exit 1 falhou, exit 2 erro de infra; JSON no stdout, relatório humano no stderr. Um flow chama validador como step runs, então uma reprovação é roteamento, não sugestão.

The bench: how you prove N agents ran together

A bancada: como se prova que N agentes rodaram juntos

The engine is single-threaded, so real concurrency does not happen inside it: it happens inside a skill, when Claude fires N subagent calls in the same message. That used to be trust in prose — the skill said "I dispatched four reviewers in parallel" and nothing verified it. The bench.ndjson ledger closes that in three beats:

O engine é single-thread, então concorrência real não acontece nele: acontece dentro de uma skill, quando o Claude dispara N chamadas de subagente na mesma mensagem. Isso era confiança em prosa — a skill dizia "despachei quatro revisores em paralelo" e nada verificava. O ledger bench.ndjson fecha isso em três tempos:

In the third beat, a runs step right after the invoke calls check-bench.js, which verifies mechanically: (a) every role in the manifest reported exactly once; (b) the consensus the skill reported to the engine matches what the agents actually said; (c) the dispatch windows overlap — proof of real concurrency, not of a sequential queue dressed up as parallel. The manifest has to be the oldest record of the round, otherwise you could shrink the list after seeing a role fail. Any violation routes back and redoes the round.

No terceiro tempo, um step runs logo depois do invoke chama check-bench.js, que verifica mecanicamente: (a) todo papel do manifesto reportou exatamente uma vez; (b) o consenso que a skill relatou ao engine bate com o que os agentes de fato disseram; (c) as janelas de despacho se sobrepõem — prova de concorrência real, não de uma fila sequencial fantasiada de paralelo. O manifesto tem que ser o registro mais antigo da rodada, senão daria para encolher a lista depois de ver um papel reprovar. Qualquer violação roteia de volta e refaz a rodada.

§8 · learning §8 · aprendizado

From a repeated error to an executable gene

De erro repetido a gene executável

Half the kit already runs on its own: validators and hooks spend no tokens and reinterpret nothing. The other half — what the change taught — is born as text the model re-reads and reinterprets every session. The DNA is the crossing from one to the other: the lesson stops being re-read memory and becomes code the organism executes.

Metade do kit já roda sozinha: validador e hook não gastam token e não reinterpretam nada. A outra metade — o que a mudança ensinou — nasce como texto que o modelo relê e reinterpreta a cada sessão. O DNA é a passagem de uma para a outra: a lição para de ser memória relida e vira código que o organismo executa.

Provenance is what lets you kill the gene later

A proveniência é o que permite matar o gene depois

Every DNA is born with a mandatory provenance header. It is not decorative metadata: without knowing under which premise the rule was created, you can never know when it stopped holding.

Todo DNA nasce com um cabeçalho de proveniência obrigatório. Não é metadado decorativo: sem saber sob que premissa a regra foi criada, nunca dá para saber quando ela deixou de valer.

That header is what check-dna-freshness cross-checks against the ADRs' supersede graph. When the ADR that held up the lesson is superseded, the DNA is marked stale and requires human revalidation — because a gate that never expires ends up becoming the bug it once caught. DNA missing the mandatory fields also fails: it exists, but there is no way to judge it.

É esse cabeçalho que o check-dna-freshness cruza com o grafo de supersede das ADRs. Quando a ADR que sustentava a lição é superseded, o DNA é marcado stale e exige revalidação humana — porque um gate que nunca expira acaba virando o bug que ele um dia pegou. DNA sem os campos obrigatórios também reprova: existe, mas não dá para julgar.

Two types, and nothing beyond: regression-gate becomes a .test.mjs in the suite's own pattern; rule becomes a .js validator under the same exit 0/1/2 contract as the others. In the full flow, the dna_gate → dna_freshness → dna_pr branch runs alongside the feature's PR without blocking it. Mixing process evolution with product delivery would pollute both.

Dois tipos, e nada além disso: regression-gate vira um .test.mjs no mesmo padrão da suíte; rule vira um validador .js no mesmo contrato exit 0/1/2 dos outros. No flow full, o ramo dna_gate → dna_freshness → dna_pr corre ao lado do PR da feature sem bloqueá-lo. Misturar evolução do processo com entrega do produto poluiria os dois.

What does not become a gene still has a destination: operational learning stays as one line read at the start of the next change, and what proves to be durable knowledge — a convention, a recurring trap, a glossary term — is proposed for promotion into the repo's shared knowledge, always via PR.

O que não vira gene ainda tem destino: aprendizado operacional fica como uma linha lida no início da próxima mudança, e o que se prova conhecimento durável — uma convenção, uma armadilha recorrente, um termo de glossário — é proposto para promoção ao conhecimento compartilhado do repo, sempre via PR.

§9 · the hook §9 · o hook

What dies before it executes

O que morre antes de executar

pre-bash runs before every Bash call in the session and blocks what governance forbids: push --force, --no-verify, git add -A, reset --hard, clean -f, branch -D, gh pr merge. The general philosophy is fail-open — when in doubt, allow, because a paranoid hook would turn into a permanent bypass. The merge rule is the deliberate inversion of that: fail-closed, only a literal form recognized as safe gets through, and any ambiguous or obfuscated shell construction dies.

O pre-bash roda antes de toda chamada de Bash da sessão e bloqueia o que a governança proíbe: push --force, --no-verify, git add -A, reset --hard, clean -f, branch -D, gh pr merge. A filosofia geral é fail-open — na dúvida, libera, porque um hook paranoico viraria bypass permanente. A regra de merge é a inversão deliberada disso: fail-closed, só passa uma forma literal reconhecida como segura, e qualquer construção shell ambígua ou obfuscada morre.

One exception has no bypass at all: rm -rf at root or home never passes.

Uma exceção não tem bypass nenhum: rm -rf em raiz ou home nunca passa.

What it is not

O que ele não é

The hook is not a security sandbox. O hook não é sandbox de segurança. It protects against accidental, inattentive use — not against a hostile agent or one hit by prompt injection: whoever wants to get around it hides the payload in a file the hook does not read. This is written in pre-bash.js's own header; it is no footnote surprise. Protege contra uso acidental e desatento, não contra um agente hostil ou vítima de prompt injection — quem quer contornar esconde o payload num arquivo que o hook não lê. Está escrito no header do próprio pre-bash.js, não é surpresa de rodapé.
The engine is not concurrent. O engine não é concorrente. Single-threaded by decision, because what matters is the state outliving the session. Real parallelism only exists in the bench pattern, inside a skill. Single-thread por decisão, porque o que importa é o estado sobreviver à sessão. Paralelismo real só existe no padrão de bancada, dentro de uma skill.
It does not replace judgement. Ele não substitui julgamento. The gates stop the advance and show the reason. Proceeding, reviewing or aborting remains the decision of whoever is reading. Os gates param o avanço e mostram a razão. Seguir, revisar ou abortar continua sendo decisão de quem está lendo.
It does not have good visibility. Ele não tem boa visibilidade. It works well from the inside, but almost everything it knows lives in markdown, JSON lines and stderr. There is no dashboard, no browsable history, no view of the process from outside. This is where the pieces are missing. Funciona bem por dentro, mas quase tudo que ele sabe vive em markdown, JSON lines e stderr. Não há painel, nem histórico navegável, nem visão de fora do processo. É aqui que faltam peças.
